# marketing/ab-copy

Catalog **skill** (no `runtime/`). Produces A/B (or multi) copy variants for humans to pick before publish.

## When to use

- After `marketing/campaign-brief` / `marketing/brand-voice`
- NL asks for variants, A/B headlines, alternate CTAs

## Downstream

Human selects a variant → optional voice check → connector under `require_human`.

No Vault binding (`auth.required=false`).
