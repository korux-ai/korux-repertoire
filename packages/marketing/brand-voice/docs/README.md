# marketing/brand-voice

Catalog **skill** (no `runtime/`). Builds or applies a brand-voice checklist; does not publish.

## When to use

- Define tone / banned phrases before a campaign
- Review upstream draft against voice before `linkedin/publish`, `mailchimp/campaign`, `wordpress/post`, …

## Downstream tip

Map `banned_phrases` into connector Owner `blocked_keywords` where supported.

No Vault binding (`auth.required=false`).
